# python.projects 🌸

a little collection of python things i'm making while learning.

nothing serious, nothing production-ready — just learning by doing, messing around with stuff, and figuring out how things work under the hood. ⋆｡‧˚ʚ

### 🌷 what's inside

**basics**

* `taschenrechner.py` — a tiny calculator for basic operations
* `passwort_generator.py` — generates random passwords
* `zahlen_raten.py` — a classic number guessing game
* `bubble_sort.py` — bubble sort, just to understand how it works
* `primzahl_check.py` — checks if a number is prime
* `palindrom_check.py` — checks if a word or sentence is a palindrome

**a little more advanced**

* `bank_konto.py` — a small bank account simulation using classes
* `fibonacci_memo.py` — fibonacci with memoization + a little speed comparison
* `quicksort.py` — a recursive sorting algorithm
* `caesar_chiffre.py` — simple text encryption + decryption
* `todo_liste_json.py` — a todo list that saves everything to a json file
* `verkettete_liste.py` — a linked list built from scratch to understand what's going on under the hood

### 🎀 running the scripts

pick a script and run it with python:

```bash
python taschenrechner.py
```

that's pretty much it. ♡
